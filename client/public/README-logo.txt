Drop the college logo here as:

    college-logo.png

Any square-ish PNG or SVG works (roughly 200x200 or larger; it is displayed
at 88px). Files in this public/ folder are copied to the site root as-is, so
the file becomes https://your-site/college-logo.png and AuthLayout.jsx picks
it up automatically.

Until the file exists, the login page shows a lettermark ("NEC") instead.
Nothing breaks, and no code needs changing when you add it.
